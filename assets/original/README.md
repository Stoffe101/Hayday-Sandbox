# assets/original — LOCAL ONLY, NEVER COMMITTED

This folder is git-ignored (except this README). It exists so a developer can
drop a locally-sourced asset pack here while testing the importer.

Only put artwork here that you are personally permitted to use. Nothing in
this folder may be committed, packaged into public builds, or redistributed.
CI fails if files other than this README appear here.

End users should import art through the app (File ▸ Import Artwork), which
stores packs in the per-user data directory instead.
