# Product vision

**"This is exactly what I wish Hay Day's layout editor could do."**

Hayday Sandbox is a personal, offline design studio for Hay Day farms. Players can experiment without spending
coins or diamonds, rearrange freely, plan future expansions and buildings, and then recreate the result in the
real game. It is a planning tool — not a replacement for Hay Day, with no farming gameplay, timers, purchases,
accounts or server integration.

## Principles

1. **Accuracy you can trust.** Footprints, map geometry and rules come from research with visible confidence
   labels. Unknown is shown as unknown — never silently guessed. A layout that "fits" here should fit in the game.
2. **Design freedom first.** Creative Mode has no limits. Realistic Mode only *reports*; it never changes a design.
3. **Feels like a real creative tool.** Cozy, coherent visuals; fast, forgiving editing (everything undoable, crash
   recovery, revisions); keyboard-friendly; great on 1080p, 1440p, ultrawide and HiDPI.
4. **Respect for Supercell's IP.** No proprietary art is distributed. Users may use their own images privately.
5. **Data-driven and sustainable.** Items, maps and art are files with schemas, validators and generators, so the
   catalogue can grow without code changes.

## Users and jobs

* *Decorator:* builds large themed gardens, seasonal redesigns — needs fast painting, lines, fills, copy/paste,
  groups, fences/paths that join nicely, beautiful exports.
* *Optimiser:* plans production districts and future machines — needs exact footprints, land planning, reserved
  space, Realistic checks for level/inventory/cost.
* *Rebuilder:* recreates the current farm as a starting point — needs screenshot reference + calibration, lockable
  core buildings, plot unlocking per plot.

## Non-goals

Gameplay simulation, production timers, multiplayer, cloud sync, account integration, automated modification of
the real game, distribution of game assets, monetisation, telemetry.
